# CRM-independent leads implementation plan

> Execution: inline, using the executing-plans workflow. No commit or external delivery requested.

**Goal:** Persist website inquiries independently of CRM availability, with a HubSpot adapter and test-only communications.

**Architecture:** Separate contacts, inquiries, durable CRM outbox and automation previews. Email identifies a contact; an idempotency key identifies a submission. A leased worker retries contact upserts with backoff. Test CRM mode makes no network requests. Emails/automations only create previews, never send or enroll contacts. Existing Wodify data and routes remain separate.

**Stack:** Existing FastAPI, SQLAlchemy, httpx, Next.js. Dedicated lightweight lead app can run without Wodify or SendGrid credentials.
