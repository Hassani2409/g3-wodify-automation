# G3 CrossFit Berlin

Existing Next.js public website, member portal and shop with a separate Python/Wodify automation backend. The owner answers inquiries personally. The website should make a first visit easy; automation is a separate service opportunity.

## This request
The user explicitly prefers the original green/orange Next.js application to the separate forest/lime premium concept. Refine that identity and existing page structure, remove generic generated marketing devices, and make the public site professional. No framework migration, production deployment or real customer-data test.

## Audience and action
Prospective Berlin members, including beginners and experienced athletes. Primary action: request a free trial, with the appointment subsequently agreed personally. Direct phone/email are alternatives.

## Facts and limitations
Studio facts and prices were sourced from g3crossfit.com in this session. Current prices, team photos and legal text still require owner confirmation. API integration has not been validated with real leads. Existing shop/member backend functionality is not being certified by this visual refinement.
